# حساب یار ری را 💰

اپلیکیشن مدیریت مالی شخصی موبایلی (فارسی، RTL) با تم سبز نعنایی پاستلی، تقویم شمسی و پشتیبانی کامل تبلت.

> **نسخه فعلی:** `v1.0.0-web` — نسخه وب کامل (Next.js + SQLite روی سرور)
> این تگ نقطه مرجع پیش از مهاجرت به **APK کاملاً آفلاین** (Capacitor + SQLite بومی دستگاه) است.

## ✨ امکانات

- 📊 **داشبورد** — موجودی کل، درآمد/هزینه امروز و ماه، نمودار ۷ روز اخیر، تراکنش‌های اخیر، پیش‌امدها
- 💳 **تراکنش‌ها** — درآمد/هزینه/انتقال، جستجو، فیلتر، ویرایش و حذف
- 🏦 **حساب‌ها** — بانکی/نقدی/پس‌انداز با موجودی اولیه و تراز خودکار
- 🏷️ **دسته‌بندی‌ها** — با آیکون و رنگ، تفکیک درآمد/هزینه
- 🎯 **بودجه‌بندی** — بودجه کل ماه + بودجه هر دسته با هشدار عبور از سقف
- 🤝 **بدهی و طلب** — مدیریت بدهی‌ها با ثبت پرداخت‌های جزئی و تسویه
- 🔁 **اقساط و دوره‌ای** — تراکنش‌های تکراری ماهانه با شمارش اقساط پرداخت‌شده
- 🐷 **اهداف پس‌انداز** — درصد پیشرفت، واریز و برداشت
- 📈 **گزارش‌ها** — ۴ بازه (روزانه/هفتگی/ماهانه/سالانه) با نمودار و تفکیک دسته‌ای
- ⏰ **یادآورها** — قبض، قسط، پس‌انداز با تکرار ماهانه/سالانه
- 📤 **خروجی و پشتیبان‌گیری** — CSV / Excel / JSON + بازیابی
- ⚙️ **تنظیمات** — فارسی/انگلیسی، تم روشن/تاریک، تقویم شمسی/میلادی، واحد پول، قفل اپ با PIN و **ورود با اثر انگشت**

## 🛠 تکنولوژی

| لایه | تکنولوژی |
|------|----------|
| فریم‌ورک | Next.js 16 (App Router) + TypeScript |
| UI | Tailwind CSS 4 + shadcn/ui + Lucide + Framer Motion |
| دیتابیس | **SQLite** (فایل، بدون سرویس ابری) + Prisma ORM |
| State | TanStack Query + Zustand |
| تقویم | جلالی (تبدیل دستی، بدون وابستگی خارجی) |
| فونت | Vazirmatn (لوکال) |

## 🚀 اجرای محلی

```bash
bun install

# دیتابیس (فایل .env را از .env.example بسازید)
cp .env.example .env
bun run db:push

bun run dev
```

> 🔒 اپ با **دیتابیس خالی** عرضه می‌شود؛ تمام اطلاعات (پروفایل، حساب‌ها، تراکنش‌ها و…) توسط خود کاربر وارد می‌شود.
> بازگشت به حالت کارخانه: `bun run db:seed`

## ☁️ دیپلوی روی Railway

اپلیکیشن یک `Dockerfile` آماده دارد و روی [Railway](https://railway.app) مستقیم اجرا می‌شود:

1. در Railway یک پروژه جدید بسازید: **New Project → Deploy from GitHub repo** و ریپو را انتخاب کنید (بیلدر Docker به‌صورت خودکار تشخیص داده می‌شود).
2. در تب **Variables** متغیر زیر را اضافه کنید:
   ```
   DATABASE_URL=file:/data/hesabyar.db
   ```
3. برای ماندگاری داده‌ها یک Volume اضافه کنید: **Service → Volumes → New Volume** با مسیر اتصال (Mount Path):
   ```
   /data
   ```
4. از تب **Settings → Networking** یک دامنه بسازید (**Generate Domain**) — HTTPS خودکار فعال می‌شود.

> 🗄 ساخت جداول در اولین اجرا به‌صورت خودکار انجام می‌شود (`prisma db push` در استارت کانتینر).
> 🔐 چون Railway دامنه HTTPS می‌دهد، **ورود با اثر انگشت (WebAuthn)** روی گوشی واقعی هم کار می‌کند.
> 💾 پشتیبان‌گیری: خروجی JSON از بخش «خروجی و پشتیبان‌گیری» داخل خود اپ.
> 🏷 Healthcheck: مسیر `/api/health`
